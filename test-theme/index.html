Features

Everything you need,
nothing you don't.

Built from the ground up in Rust for maximum performance and safety.

Rust-powered engine

Native Node.js bindings via napi-rs. Uses memory-mapped files, parallel processing, and xxHash caching. Sub-100ms builds on real projects.

Cold build 34ms
Incremental 1.2ms

Secure by default

CSS injection blocked at the Rust layer. Arbitrary values are sanitized — no javascript: URLs, no escapes.

Tailwind compatible

Drop-in replacement. Same class names, same patterns. Your muscle memory works.

Container queries

Named containers like @sm/card:flex work out of the box.

Dynamic spacing

Any number works. p-13, m-99, w-123. No config needed.

Same code,
way more speed

Garur's API is identical to Tailwind's. Migrate by changing one line.
